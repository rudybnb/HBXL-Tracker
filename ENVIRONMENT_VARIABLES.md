# 🔑 Environment Variables Reference

## Complete list of environment variables needed for Render deployment

---

## 🌐 Node.js Web Service (`erdesignandbuild-web`)

### Database (Required)
```bash
DATABASE_URL=postgresql://username:password@hostname:5432/database_name
```
**Where to get**: Your Render PostgreSQL database connection string

---

### Session Security (Required)
```bash
SESSION_SECRET=<generate-random-32-character-string>
```
**How to generate**:
```bash
# Linux/Mac
openssl rand -base64 32

# Or use online generator
# https://randomkeygen.com/
```

---

### Twilio Voice Assistant (Required for voice features)
```bash
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_PHONE_NUMBER=+1234567890
```
**Where to get**: https://console.twilio.com
- Account SID: Dashboard → Account Info
- Auth Token: Dashboard → Account Info → Auth Token
- Phone Number: Phone Numbers → Manage → Active numbers

---

### ElevenLabs Text-to-Speech (Required for voice features)
```bash
ELEVEN_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
ELEVEN_VOICE_ID=xxxxxxxxxxxxxxxxxx
```
**Where to get**: https://elevenlabs.io
- API Key: Profile → API Keys → Generate new key
- Voice ID: Voices → Choose voice → Copy Voice ID
  - Recommended: Bella (female, friendly)

---

### SendGrid Email (Optional)
```bash
SENDGRID_API_KEY=SG.xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```
**Where to get**: https://app.sendgrid.com
- Settings → API Keys → Create API Key
**Required permissions**: Mail Send

---

### Python API Connection (Required - Set AFTER Python service deployed)
```bash
PYTHON_API_URL=https://erdesignandbuild-telegram-api.onrender.com
```
**Where to get**: Render dashboard → Python service → URL

---

### Finance API (Optional - if using external finance app)
```bash
FINANCE_API_BASE=https://your-finance-app.replit.app
```
**Where to get**: Your finance application URL

---

### System Variables (Auto-set by Render)
```bash
NODE_ENV=production
PUBLIC_URL=<auto-generated-by-render>
PORT=<auto-assigned-by-render>
```
**Note**: Don't set these manually, Render handles them

---

## 📋 Environment Variable Checklist

### Before Deploying Node.js Service:
- [ ] DATABASE_URL (from Render PostgreSQL)
- [ ] SESSION_SECRET (generated random string)
- [ ] TWILIO_ACCOUNT_SID
- [ ] TWILIO_AUTH_TOKEN
- [ ] TWILIO_PHONE_NUMBER
- [ ] ELEVEN_API_KEY
- [ ] ELEVEN_VOICE_ID
- [ ] SENDGRID_API_KEY (if using email)
- [ ] FINANCE_API_BASE (if using)

### After Python Service Deployed:
- [ ] PYTHON_API_URL (from Python service URL)

### Before Deploying Python Service:
- [ ] DATABASE_URL (from Render PostgreSQL)

## 🔒 Security Best Practices

### DO:
✅ Use Render's environment variable dashboard
✅ Keep API keys secret
✅ Use different keys for staging vs production
✅ Rotate keys periodically
✅ Generate strong random SESSION_SECRET

### DON'T:
❌ Commit .env files to git
❌ Share API keys in screenshots
❌ Use weak SESSION_SECRET values
❌ Hardcode secrets in code
❌ Reuse the same keys across projects

## 🧪 Testing Environment Variables

### Test Database Connection:
```bash
# From your local machine
psql "postgresql://username:password@hostname:5432/database_name"
```

### Test Twilio Credentials:
```bash
curl -X GET "https://api.twilio.com/2010-04-01/Accounts.json" \
  -u "TWILIO_ACCOUNT_SID:TWILIO_AUTH_TOKEN"
```

### Test ElevenLabs API Key:
```bash
curl -X GET "https://api.elevenlabs.io/v1/voices" \
  -H "xi-api-key: YOUR_API_KEY"
```
